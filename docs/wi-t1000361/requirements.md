# 需求：画一朵月季

## 目标
应用运行时在主界面上呈现一朵月季花的图形，让用户可以直接看到成品画面。

## 核心行为与规则
- 用户明确提出：呈现对象为「一朵月季」，即 Rōsa chinensis（月季/月月红），需与玫瑰、蔷薇、其他花卉在画面上可区分；画面内主体仅此一朵，不做多株、花束或花园场景。
- 主体构成（推荐基线，可后续调整）：月季花头应能观察到的元素包括层叠花瓣、花心，以及作为月季辨识特征的枝条或叶片；不要求写实照片级细节，但应让人辨认出是月季而不是抽象色块。
- 渲染方式（SVG、Canvas、CSS、位图素材等）：未规定。实现选型不属于产品基线，只要用户能在浏览器/应用主界面看到一朵完整月季即可。
- 交互与动态：未规定。用户未提出可交互绘制、动画、缩放、换色、多视角或保存导出等诉求；本次基线不承诺这些行为，如需追加另行确认。
- 受众与场景：未规定。用户未指定使用人群或业务上下文，本次基线按「打开应用即看到一朵月季」这一最小可观察结果处理，不推断角色、权限或多端形态。

## 验收

### AC-01：应用主界面渲染一朵完整月季
- 验收条件：用户启动应用并进入主界面后，能够在页面上直接观察到一朵月季花图形，画面主体为一朵月季，且形态可辨识为月季（花瓣层叠、含花心，附枝条或叶片），而非其他花卉或抽象图形。
- 入口类型：用户界面
- 验证动作：启动应用；打开其默认主界面；观察主体图形，不做任何交互操作。
- 预期结果：主界面稳定显示一朵月季花的完整画面，画面中不出现其他花朵或干扰主体识别的图形元素；关闭并重新打开应用后仍呈现同一朵月季（不要求逐帧一致的动画结果，只要求同一静态主体可再次呈现）。
- 证据类型：runtime-render, visual-style
