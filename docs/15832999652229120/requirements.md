## 1. 项目背景与目标

### 1.1 背景

用户希望获得一个能够**绘制三角形**的能力：在打开的页面上呈现一个三角形，并能够由用户自己把三角形画出来。当前工作区没有既有的产品材料或代码基线，因此本需求以用户提出的目标作为唯一来源。

### 1.2 服务对象

需要在页面上查看或自己动手画一个三角形的人（学习几何图元的初学者、需要快速示意三角形形状的使用者）。用户未提出角色划分或多用户协作诉求。

### 1.3 成功结果

- 打开页面即可看到一个三角形，形状（三条边、三个顶点）清晰可辨；
- 用户可以用鼠标在页面上自己确定三个顶点，从而画出一个三角形；
- 用户可以把已画出的三角形清掉并重新绘制。

### 1.4 目标设备

桌面 Web 浏览器（用户未提出移动端或窄屏适配要求，本需求不将移动端列为必需项）。

## 2. 用户旅程与关键场景

### 2.1 旅程 J-01：查看三角形

打开页面 → 页面直接呈现一个三角形 → 用户目视确认三条边与三个顶点完整可见。

- 关键反馈：图形在页面加载完成后即可见，无需额外操作。

### 2.2 旅程 J-02：自己画出三角形

打开页面 → 在绘制区域依次点击三个位置 → 每点一处，前面已确定的顶点之间连成边 → 第三个顶点确定后，形成一个闭合的三角形 → 用户确认所画三角形符合预期。

- 关键决策点：第三个顶点落在与前两点同一直线上时，图形无法构成三角形，需要给出提示而不是画出退化图形。
- 关键反馈：点击过程可见顶点标记；第三个顶点确定后图形闭合。

### 2.3 旅程 J-03：清空并重画

完成一次绘制 → 点击清空 → 绘制区域恢复为无图形状态 → 重新点击三个位置，画出新的三角形。

- 关键反馈：清空后不残留上一次的顶点和边；重新绘制不受上一次影响。

## 3. 状态模型与业务规则

### 3.1 绘制状态（推荐基线）

| 状态 | 含义 | 可进入的下一状态 |
| --- | --- | --- |
| 空闲 | 绘制区域没有用户绘制的图形，或已清空 | 绘制中 |
| 绘制中 | 已确定 1 个或 2 个顶点，尚未构成三角形 | 绘制中、已完成、空闲 |
| 已完成 | 已确定 3 个有效顶点，三角形闭合可见 | 绘制中（开始新的绘制）、空闲 |

### 3.2 通用业务规则

- **BR-01（推荐基线）**：一个三角形由三个不在同一直线上的顶点唯一确定。
- **BR-02（推荐基线）**：顶点数量少于 3 时不构成三角形，不绘制闭合图形。
- **BR-03（推荐基线）**：三个顶点共线时不构成三角形，给出提示并保持图形不闭合。
- **BR-04（推荐基线）**：清空操作后，绘制区域不保留任何顶点或边，状态回到空闲。
- **BR-05（推荐基线）**：绘制区域内的图形只反映用户当前这一次绘制的结果；开始新的绘制时，前一次的顶点与边不再保留。

## 4. 分模块功能需求

### 4.1 M-01 三角形呈现

- **FR-M01-01**：页面加载完成后，绘制区域显示一个三条边闭合、三个顶点可见的三角形（推荐基线：默认呈现一个位置居中的三角形，便于用户立即看到效果）。
- **FR-M01-02**：三角形在绘制区域内完整可见，三条边均不超出绘制区域边界。
- **FR-M01-03**：三角形的三条边与三个顶点可被用户目视区分（推荐基线：以可见描边呈现边与顶点）。

### 4.2 M-02 交互绘制

- **FR-M02-01**：用户可在绘制区域内通过点击确定顶点；每确定一个顶点，该顶点在区域内留下可见标记。
- **FR-M02-02**：在顶点数量达到 2 个后，已确定的顶点之间显示连接的边（推荐基线：实时预览，便于用户在落第三点前看到形状走向）。
- **FR-M02-03**：当第 3 个顶点确定且三个顶点不共线时，图形闭合为三角形，状态变为已完成。
- **FR-M02-04**：当第 3 个顶点与前两个顶点共线时，不生成三角形，并给出提示信息，说明三个点不能构成三角形（异常处理）。
- **FR-M02-05**：顶点确定于绘制区域之外的位置时，该次操作不计入顶点（边界处理）。
- **FR-M02-06**：用户在已完成状态下继续点击时，之前的三角形不再保留，从新图形的第一个顶点开始绘制（推荐基线）。

### 4.3 M-03 清空与重绘

- **FR-M03-01**：提供清空入口，触发后绘制区域不残留用户绘制的顶点与边。
- **FR-M03-02**：清空后用户可立即重新绘制，绘制过程与清空前的操作表现一致。
- **FR-M03-03**：页面加载后若用户尚未操作，清空入口被触发时不影响默认呈现的三角形（推荐基线：清空操作只针对用户绘制结果）。

## 7. 验收场景

### AC-01：页面加载后显示三角形
- 验收条件：页面加载完成后，绘制区域显示一个由三条边闭合、三个顶点可见的三角形。
- 入口类型：用户界面
- 前置条件：页面可访问。
- 触发动作：打开页面。
- 验证动作：打开页面，查看绘制区域内的图形。
- 预期结果：绘制区域内存在一个三条边闭合、三个顶点可见的三角形。
- 证据类型：runtime-render

### AC-02：点击三个不共线位置画出三角形
- 验收条件：在绘制区域依次点击三个不共线的位置后，三个顶点之间连成边并闭合为一个三角形。
- 入口类型：用户界面
- 前置条件：页面已打开。
- 触发动作：在绘制区域内依次点击三个位置，三点不共线。
- 验证动作：依次点击三个位置，观察绘制区域。
- 预期结果：三个顶点均留下可见标记，且三条边连成闭合三角形。
- 证据类型：runtime-render, interaction
- 共享流程组：绘制三角形

### AC-03：顶点不足时不形成闭合图形
- 验收条件：只确定 1 个或 2 个顶点时，绘制区域不出现闭合的三角形。
- 入口类型：用户界面
- 前置条件：页面已打开，且已清空用户绘制结果。
- 触发动作：在绘制区域内点击 1 次，然后点击第 2 次。
- 验证动作：点击两个位置后观察绘制区域。
- 预期结果：可见 2 个顶点标记及连接它们的线段，但不存在闭合的第三条边。
- 证据类型：interaction
- 共享流程组：绘制三角形

### AC-04：三点共线时给出提示且不生成三角形
- 验收条件：当第三个顶点落在前两个顶点确定的直线上时，不生成三角形，并给出说明三个点无法构成三角形的提示。
- 入口类型：用户界面
- 前置条件：页面已打开，已清空用户绘制结果。
- 触发动作：依次点击三个位于同一直线上的位置。
- 验证动作：点击三个共线位置后观察页面提示与绘制区域。
- 预期结果：页面出现提示信息，绘制区域不出现闭合三角形。
- 证据类型：error-feedback
- 共享流程组：绘制三角形

### AC-05：清空后不残留图形且可重新绘制
- 验收条件：触发清空后，绘制区域不残留用户绘制的顶点与边；再次点击三个不共线位置可画出新的三角形。
- 入口类型：用户界面
- 前置条件：已通过三次点击画出一个三角形。
- 触发动作：触发清空入口，然后再次依次点击三个不共线位置。
- 验证动作：触发清空后查看绘制区域，再重新点击三个位置。
- 预期结果：清空后无用户绘制的顶点与边残留；重新点击三个位置后出现新的闭合三角形。
- 证据类型：interaction, runtime-render
- 共享流程组：清空重绘

### AC-06：绘制区域外的点击不计入顶点
- 验收条件：在绘制区域之外点击时不增加顶点，绘制状态不因该次点击而改变。
- 入口类型：用户界面
- 前置条件：页面已打开，已清空用户绘制结果。
- 触发动作：在绘制区域之外的页面区域点击。
- 验证动作：在区域外点击后查看绘制区域。
- 预期结果：绘制区域内没有任何新增顶点标记，绘制状态保持为未开始。
- 证据类型：interaction
