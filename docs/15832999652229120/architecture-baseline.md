## 1. 整体方案与设计基线

### 1.1 应用形态结论

**纯前端单页应用（React + Vite SPA）**，运行在桌面浏览器中。不引入服务端进程、不使用 Hono、不使用数据库，也不引入任何公共模块：

- 需求中的全部行为都发生在页面内：加载即呈现三角形、用户点击确定顶点、第三个顶点闭合三角形、清空后重绘；
- 需求明确页面刷新后不要求保留绘制结果（NFR-01），因此没有需要服务端或数据库承载的权威数据；
- 需求不涉及登录认证、角色权限、后台任务、外部服务与跨用户/跨设备共享数据。

判定依据为已批准需求基线中"服务对象、成功结果、非功能要求"三节的明确表述，而非技术偏好；本设计不为非必需能力引入服务端、数据库、缓存或存储方案。

### 1.2 实现入口与运行方式

- **实现入口**：单页应用的页面根组件，承载绘制区域与清空入口；具体文件路径与组件划分由实现阶段按工作区现有约定落地，本设计不预先指定文件。
- **运行方式**：以本地开发服务器提供页面，由浏览器访问；启动命令沿用工作区 `package.json` 中的脚本约定，实现阶段确定并冻结为默认启动命令。
- **运行契约**：无服务端监听端口、无数据库文件路径、无健康检查接口；验收按页面在浏览器中的真实呈现与交互进行。
- **不产出的产物**：本应用没有需要前后端共同遵守的 API 契约，因此不生成技术契约文件；不执行工作区初始化，因此不生成初始化配置；不存在影响系统边界的真实取舍，因此不生成架构决策记录。

### 1.3 最小架构约束

- 状态只存在于页面运行内存：当前顶点集合与绘制状态不落盘、不跨刷新保留；
- 绘制区域内部只依赖"用户点位"与"当前顶点集合"两类输入，不依赖任何外部数据源；
- 共线判定与提示属于页面内即时反馈，不产生异步等待或重试。

## 2. 领域责任、模块边界与接口摘要

本应用只有两个内部模块，没有服务端层、没有数据库访问层、没有对外能力接口。

### 2.1 M-01 绘制区域（DrawingSurface）

- **模块职责**：把顶点集合渲染为可见的顶点标记与边；在顶点数达到 3 时判定三点是否共线并决定闭合或提示；维护页面加载时的默认示例三角形。
- **核心事实唯一归属**：本模块唯一拥有"用户当前这一次绘制的顶点集合"与"绘制状态（空闲 / 绘制中 / 已完成）"。任何其他模块不得自行解释或复制顶点数据。
- **接口摘要（页面内调用，非 HTTP 接口）**：
  - `addVertex(point)`：加入一个顶点，返回本次加入后的顶点数量与是否构成有效三角形；当第三个顶点与前两点共线时返回不可构成三角形的结果，由页面给出提示；
  - `clear()`：清空用户绘制的顶点与边，状态回到空闲；
  - `resetToDefault()`：恢复页面加载时的默认示例三角形。
- **边界处理**：落在绘制区域之外的点位不由本模块接收，因此不改变顶点集合与绘制状态。

### 2.2 M-02 页面外壳（Page Shell）

- **模块职责**：页面布局与文案呈现；承载绘制区域容器、清空入口与提示信息区域；承接用户在绘制区域内的点击并把点位交给绘制区域，丢弃绘制区域之外的点击。
- **核心事实唯一归属**：本模块拥有页面级呈现状态（提示信息是否可见、清空入口是否可用），不拥有任何顶点数据。
- **接口摘要**：向绘制区域调用 `addVertex`、`clear`；从绘制区域读取"当前顶点集合、绘制状态"用于呈现。

### 2.3 数据归属与生命周期小结

| 事实 | 唯一归属 | 存放位置 | 生命周期 |
| --- | --- | --- | --- |
| 用户绘制顶点集合 | M-01 绘制区域 | 页面运行内存 | 页面打开期间；刷新或关闭页面即销毁 |
| 绘制状态（空闲/绘制中/已完成） | M-01 绘制区域 | 页面运行内存 | 同上 |
| 提示信息、清空入口可用性 | M-02 页面外壳 | 页面运行内存 | 同上 |

不涉及数据库、数据关系、迁移与外部集成，因此不设相应章节。

## 3. UI 基线

- **目标设备**：桌面 Web 浏览器（需求 1.4 未提出移动端或窄屏要求，本设计不把窄屏适配列为必需项）。
- **应用壳与导航**：单页面、无导航结构；页面主体为绘制区域。
- **主工作流布局**：标题/说明文案 + 绘制区域（占页面主体）+ 清空入口；提示信息在绘制区域附近就近呈现，不使用弹窗打断绘制。
- **视觉风格方向**：以图形清晰可辨为唯一目标，保持简洁；三角形描边与顶点标记需与背景形成可见对比，顶点标记与边可区分；具体色值与字号由实现阶段按项目现有样式基线落地。
- **状态呈现**：空闲（可提示用户点击三个位置开始绘制）、绘制中（显示已确定顶点及已连成的边）、已完成（闭合三角形可见）、三点共线异常（就近提示三个点不能构成三角形，且图形不闭合）。加载中、无数据、无权限状态不适用本应用。
- **展示模板**：沿用项目默认样式基线，不选用额外展示模板。
