# “画一朵牡丹”需求基线

- WorkItem: wi-t1000346
- 交付档位：standard
- 复杂度判定：单一作品交付，无多角色、无流程分支，属简单需求；按目标、核心规则、一条最小充分 AC 收口。

## 1. 目标

交付一幅“一朵牡丹”的数字绘画作品文件：画面主体为一朵盛开的牡丹，明确呈现牡丹的典型形态特征，产物为可查看、可保存的数字图像文件。

## 3. 核心规则（行为与约束）

R1 主体唯一（用户明确提出）
画面主体为一朵盛开的牡丹；不出现多朵相互争艳的牡丹花头。未开花的花苞不作为主体；允许以花苞、叶、枝作为陪衬元素。

R2 典型形态特征必须可辨认（用户明确提出）
观看图像时，以下三项牡丹形态特征应同时可辨认：
- 层叠花瓣：花瓣呈内外多层叠合结构，而非单层环状排列；
- 饱满花头：盛开的花头丰满圆润，占据画面视觉中心；
- 枝叶衬托：花头周围有牡丹叶和枝作为衬托，层次上从属于主体花头。

R3 产物形态（用户明确提出）
- 交付一个数字图像文件，可作为普通文件保存；
- 该文件可直接查看（例如用浏览器或图像查看器打开即可呈现完整画面，无需附带运行环境）；
- 格式为 SVG 或位图（PNG 等）任一即可【用户明确提出：二者择一即可】。

R4 推荐基线（可调整）
- 默认采用 SVG 矢量格式作为推荐基线：单文件、浏览器可直接查看、放大不失真；若实现阶段选择位图（如 PNG），同样满足 R3。
- 画面背景、配色风格（写实／国画／插画等艺术风格）、尺寸比例均未由用户指定，保持未规定；任何能让 R1、R2 特征清晰可辨的表现方式均可接受。
- 交付位置与命名保持未规定，但产物必须是本工作区内用户可获得的具体文件，不能仅是聊天中的描述或代码片段。

## 4. 验收标准

### AC-01：交付可查看、可保存的“一朵牡丹”图像文件，画面体现牡丹典型形态特征
- 验收条件：
  1. 工作区中存在一个牡丹图像文件（SVG 或位图），可作为普通文件保存／复制；
  2. 用浏览器或图像查看器直接打开该文件，可正常渲染完整画面；
  3. 渲染画面同时满足：
     - 主体为一朵盛开的牡丹（单一花头，R1）；
     - 花瓣呈内外多层叠合结构（R2-层叠花瓣）；
     - 花头丰满圆润并处于画面视觉中心（R2-饱满花头）；
     - 花头周围可见叶与枝的衬托（R2-枝叶衬托）。
- 入口类型：用户界面（打开并查看图像文件的交互入口，不指定页面布局或产品载体）
- 验证动作：定位交付的图像文件；在浏览器或图像查看器中打开它；观察画面主体数量与开花状态、花瓣层数结构、花头形态与位置、枝叶是否存在。
- 预期结果：文件正常打开渲染；画面主体是一朵盛开的牡丹而非花苞或多朵花头；可见多层叠合的花瓣；花头饱满且位于视觉中心；花头周围有叶与枝衬托。
- 证据类型：visual-style, other（文件存在性与可直接查看性）
