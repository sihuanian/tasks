# 需求基线：画一朵康乃馨

## 目标

产出一张可查看的康乃馨图像，用户打开后即可辨认出这是一朵康乃馨，并呈现其典型形态特征。

## 核心行为与规则

- 图像内容为单朵康乃馨（用户明确提出）。
- 花瓣：扇形边缘带锯齿状缺刻，多层重叠形成重瓣效果（用户明确提出）。
- 花冠：整体呈杯状（用户明确提出）。
- 茎叶：花茎直立，茎上叶片细长且成对生长（对生）（用户明确提出）。
- 配色：粉色系等常规配色（用户允许按需选择；推荐基线：花瓣用粉色深浅层次表现重瓣，茎与叶用常规绿色）。
- 交付载体（用户给出示例"SVG 矢量图或代码绘制页面"，未强制二选一；推荐基线）：以 SVG 矢量图形绘制整朵康乃馨，并放入一个单文件 HTML 页面中呈现；页面打开即显示图像，同时 .svg 文件本身可独立直接查看。此选择保守、可逆，不影响后续调整。
- 图像为静态展示。缩放、动画、下载、交互编辑等能力用户未提到，本基线不含相应承诺。

## 验收场景

### AC-01：康乃馨图像可作为可查看文件交付
- 验收条件：存在用户可直接打开查看的康乃馨图像产物，打开后页面内即呈现该图像，无需额外操作。
- 入口类型：用户界面
- 验证动作：在浏览器中打开交付的页面文件（或直接打开交付的 .svg 文件），观察页面显示内容。
- 预期结果：页面正常显示，视口内呈现一朵完整的康乃馨图像，无空白页、破图或报错。
- 证据类型：runtime-render, visual-style

### AC-02：图像呈现康乃馨的典型形态特征
- 验收条件：从查看的图像中可辨认出用户提出的各形态特征：扇形锯齿状重瓣花瓣、杯状花冠、直立茎、对生细叶；配色属于粉色系等常规花卉配色。
- 入口类型：用户界面
- 验证动作：打开图像后逐项观察并记录：① 花瓣外缘是否呈扇形且带锯齿状缺刻；② 花瓣是否多层重叠形成重瓣花头；③ 花头整体是否呈杯状轮廓；④ 花茎是否直立；⑤ 茎上叶片是否细长且左右成对（对生）分布；⑥ 整体配色是否为粉色系花瓣加常规茎叶色。
- 预期结果：上述 6 项特征均可在图像中观察到；缺少任一特征或有明显歧义（如花瓣边缘平滑无锯齿、叶片互生而非对生）判为不通过。
- 证据类型：visual-style
