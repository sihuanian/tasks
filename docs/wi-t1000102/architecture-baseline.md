## 1. 整体方案与设计基线

### 技术形态与实现入口

- 形态：单页浏览器应用（SPA），全部逻辑与状态运行在用户当前浏览器页面内，交付物为静态资源。
- 技术栈：React + Vite（构建与本地运行）。不引入服务端进程、数据库、鉴权、消息队列或第三方外部服务。
- 实现入口：工作区根目录的应用为 Vite 项目，页面入口为根目录 `index.html`，应用代码位于 `src/`（`src/main.tsx` 挂载根组件，`src/App.tsx` 组织工作区装配）。无服务端入口文件。
- 运行方式：开发运行使用 Vite 开发服务器；交付验证使用静态构建产物（`vite build`）经本地静态方式加载。应用不定义监听端口、数据库路径或后台进程参数，也不存在需要部署的服务端组件。
- 交付边界：本应用不以“已部署”“已发布”为前提；页面可由任意静态方式承载，验收在真实浏览器中针对页面行为进行。

### 页面与交互边界

- 单一工作区页面：一个画布区域加一组常驻工具栏动作（生成笑脸、笔触颜色、笔触粗细、撤销、清空、导出图片）。无多页面路由、无登录页、无导航壳。
- 画布为页面内的固定比例绘制面，随窗口宽度自适应并保持比例；页面加载完成即可接受指针输入。
- 指针输入语义：按下开始一笔、移动持续补充笔迹、抬起结束当前一笔；指针离开画布区域后不再产生新笔迹，返回画布后从返回点继续，不在离开与返回位置之间补线。
- 动作可执行性：撤销在无历史操作时仍可触发且保持画布不变，不产生错误提示；清空与导出针对当前画布内容生效。
- 绘制与生成共用同一画布表面：生成笑脸替换画布当前内容，且该次替换作为一次可撤销操作进入历史。

### 状态与数据归属

- 绘制内容（当前画布上的笔迹集合）由浏览器页面内存唯一持有，作为唯一事实来源；页面刷新不承诺保留内容，需求未要求跨会话留存，因此不引入持久化存储或后端存储。
- 操作历史（用于逐步撤销）由页面内存中的操作栈持有，与画布内容同源、同一模块维护，避免两处状态互相推导产生不一致。
- 工具配置（当前笔触颜色、粗细档位）为页面级 UI 状态，仅作用于其后新产生的笔迹，不回溯修改既有笔迹。
- 导出为一次性读取当前画布快照并生成本地文件，不写入任何远端或本地持久通道之外的存储。

### 运行与失败边界

- 应用无网络依赖即可完成全部核心动作，因此不存在接口失败、超时重试或服务端错误分支；可预见的失败边界限于浏览器端能力（指针事件、画布导出），失败时以页面内提示呈现且不阻断其它动作。
- 页面面向桌面浏览器视口使用，工具栏与画布在常见桌面分辨率下均完整可见可操作。

## 2. 领域责任、模块边界与接口摘要

本应用为单页面客户端应用，无服务端层、无跨模块网络调用；模块均在同一前端运行时内以组件与纯逻辑单元协作，调用方向为「页面组件 → 功能模块 → 画布表面」。

### 模块职责与数据归属

| 模块 | 职责 | 数据/事实归属 | 主要接口摘要 |
| --- | --- | --- | --- |
| 绘图表面模块（画布） | 持有并渲染画布内容；接收指针输入并实时呈现笔迹；对外提供画布快照读取能力 | 画布内容的唯一持有者与唯一渲染出口 | 对外：开始一笔、追加一段笔迹、结束一笔、请求当前快照、整体替换内容、清空 |
| 操作历史模块 | 记录可撤销的绘制操作（一笔笔迹或一次生成笑脸）并按序回退 | 撤销历史的唯一持有者 | 对外：记录一次操作、撤销最近一次操作、查询是否可撤销 |
| 笔触配置模块 | 维护当前笔触颜色与粗细档位，供新笔迹消费 | 当前工具配置的唯一持有者 | 对外：读取当前颜色与粗细、设置颜色、设置粗细 |
| 笑脸生成模块 | 依据画布尺寸计算标准笑脸几何（脸部轮廓、两只眼睛、向上弯曲的嘴部），产出一次绘制操作的图形描述 | 无持久状态，仅产出图形描述 | 对外：按目标画布尺寸生成笑脸图形描述 |
| 导出模块 | 将当前画布快照编码为 PNG 并触发浏览器本地下载 | 无持久状态，仅做一次性转换与触发 | 对外：依据画布快照产出 PNG 数据与下载文件 |
| 工作区装配组件 | 组合画布、工具栏与各动作，负责动作编排（生成、撤销、清空、导出）与状态订阅 | 无独立业务事实，仅编排与展示 | 对外：无，被页面入口挂载 |

### 关键协作与边界约定

- 撤销的语义边界：由操作历史模块定义“可撤销单位”，绘图表面模块只负责按该单位应用或回退，双方不各自解释历史。
- 生成笑脸与自由绘制写入同一画布内容，因此两者的追加/替换都必须经由操作历史模块登记，保证撤销可连续进行。
- 撤销、清空、导出均读取同一份画布事实，不允许任何模块自行缓存画布副本来判断内容是否存在。
- 工具配置只影响后续笔迹的生成参数，绘制开始时应读取当前配置并随该笔固定，避免绘制过程中改配置导致半笔变色或半笔变粗。
- 无 UI 入口的能力：像素级导出编码与笑脸几何计算为内部逻辑单元，不提供独立界面入口，分别由工作区装配组件的导出动作与生成动作触发。
